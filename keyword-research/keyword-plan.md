# Keyword research plan

## Seed clusters
Validate every term against the actual product and landing page before bidding.

| Cluster | Example seed terms | Notes |
|---|---|---|
| Dental study | dental study resources, dental learning platform | Broad intent; qualify with landing-page relevance |
| Visual learning | visual learning dentistry, dental anatomy learning | Use only if the product genuinely supports visual learning |
| Exam preparation | dental exam preparation, dental MCQ practice | Target only exams and question-bank features actually offered |
| Subject-specific | oral pathology study, oral surgery study resources | Create separate groups only where relevant content exists |
| Brand | SketchRoot, SketchRoot dental learning | Keep separate from non-brand campaigns |

## Research workflow
1. Enter seed terms into Google Keyword Planner for each intended country/region and language.
2. Export monthly searches, competition, and bid estimates with the date and targeting settings.
3. Inspect the live search results and search intent.
4. Map each keyword group to one relevant landing page.
5. Add negative keywords based on irrelevant search terms.
6. Revisit after launch using actual Search Terms report data.

## Negative keyword candidates to review
Potentially irrelevant modifiers may include: jobs, salary, free download, torrent, pirated, and unrelated non-dental meanings. Do **not** apply these blindly; check whether legitimate users might use them.

## Required fields for a working sheet
Keyword, match type, intent, geography, language, landing page, estimated volume, estimated CPC, competition, negative candidate, validation date, status, notes.

No search volumes or CPCs are stated here because they must be pulled from current account/Keyword Planner data.
