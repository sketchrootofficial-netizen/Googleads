# Conversion tracking and measurement plan

## Recommended events
Choose events that the website can reliably measure:
- **Primary:** completed registration or another verified business outcome.
- **Secondary:** signup start, key product-page engagement.
- **Diagnostics:** landing-page view, CTA click, form error (not a primary conversion).

Do not count every page view or CTA click as a completed signup.

## Setup checklist
- [ ] Confirm Google Ads and GA4 account ownership and access.
- [ ] Define primary vs secondary conversions before implementation.
- [ ] Configure Google tag or an approved tag-management setup.
- [ ] Avoid duplicate counting between imported GA4 events and Google Ads tags.
- [ ] Configure consent controls and privacy disclosures where required.
- [ ] Test on desktop and mobile using tag diagnostics and test conversions.
- [ ] Confirm conversion windows, attribution, and counting method.
- [ ] Document event name, trigger, destination, owner, and test date.

## Weekly reporting fields
Date range, campaign, ad group, spend, impressions, clicks, CTR, average CPC, conversions, conversion rate, cost per conversion, qualified signups (if measurable), landing page, changes made, next action.

## Important
Do not put personally identifiable information in URLs, event names, or advertising parameters. Never commit API secrets or credentials to this repository.
